# Лабораторная работа №1: Первичное исследование и оценка качества данных

## О проекте
Проект посвящен анализу датасета `flavors_of_cacao.csv`, содержащего информацию об обзорах крафтового шоколада. 
Цель работы — провести аудит качества данных, выявить проблемы и построить первичные визуализации.

## Структура проекта
- `data/` — исходный датасет.
- `notebooks/01_data_understanding.ipynb` — Jupyter Notebook с кодом анализа.
- `report/quality_report.md` — текстовый отчет с выводами и планом очистки данных.
- `.gitignore` — файлы, исключенные из репозитория.

## Как запустить
1. Установите зависимости: `pip install pandas numpy matplotlib seaborn jupyter`
2. Перейдите в папку `notebooks/` и запустите Jupyter Notebook: `jupyter notebook`
3. Откройте `01_data_understanding.ipynb` и выполните все ячейки (`Kernel -> Restart & Run All`).
